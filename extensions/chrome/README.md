# NovaLoad Browser Extension — Chrome (v1.0.0)

## Package Contents
Self-contained Chrome Manifest V3 extension (`manifest.json`, `background.js`, `popup.html`, `popup.js`, `icons/`).

## Unpacked Installation (Chrome)
1. Extract `NovaLoad-Chrome-Extension-v1.0.0.zip` to a permanent folder.
2. Launch NovaLoad Desktop (or local server) and open **Browser Bridge** to copy your **Handoff Endpoint** and **Pairing Token** (`nl_bridge_...`).
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode** in the top-right corner.
5. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
6. Pin **NovaLoad Download Bridge** to your toolbar, paste your Endpoint + Token, and click **Test Connection**.
