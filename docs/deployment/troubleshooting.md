# Deployment Troubleshooting

## Common Issues

### `node:sqlite` Import Error
- **Symptom**: `Cannot find module 'node:sqlite'` on startup.
- **Fix**: Upgrade Node.js to `22.5.0` or newer (`CI` targets Node `22`).

### Missing Linux WebKitGTK Libraries
- **Symptom**: `cargo test` or `cargo tauri build` fails linking `webkit2gtk-4.1` or `javascriptcoregtk`.
- **Fix**: Install `libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf rpm`.

### Missing Frontend `dist/` in Production Mode
- **Symptom**: Express responds with `ENOENT: no such file or directory, stat '.../dist/index.html'` when `NODE_ENV=production`.
- **Fix**: Run `npm run build` before `NODE_ENV=production npm start`.

### Updater Endpoint 404
- **Symptom**: Desktop updater logs an HTTP 404 for `latest.json`.
- **Fix**: Verify a published (non-draft) GitHub Release under `Developer04ZF/NovaLoad` includes `latest.json` generated by `tauri-apps/tauri-action` with `TAURI_SIGNING_PRIVATE_KEY` configured.
