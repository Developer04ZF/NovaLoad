# Brand Guidelines

![NovaLoad Logo](../../assets/branding/logo.svg)

## Product Identity
- **Product Name**: NovaLoad
- **Tagline**: *Download smarter. Manage everything.*
- **Primary Mark (`assets/branding/logo-mark.svg`)**: Rounded cobalt container (`#2563EB` → `#1D4ED8`) framing an orbital transfer arc (`#93C5FD`) and a crisp downward transfer arrow.
- **Full Logo (`assets/branding/logo.svg`)**: Horizontal lockup combining the mark and `NovaLoad` wordmark (`assets/branding/wordmark.svg`).
- **Hero Composition (`assets/branding/hero-banner.svg`)**: Architectural dark-slate grid (`#0B0E14`), parallel Range segment bars, and Novi mascot in active transfer pose.

## Usage Rules
- Preserve minimum clear space equal to `25%` of the logo mark width around all sides.
- Keep vector edges sharp (`stroke-linecap="round"`, `stroke-linejoin="round"`).
- Do not distort proportions, invert text onto low-contrast surfaces, or substitute random stock emojis for official NovaLoad marks.
