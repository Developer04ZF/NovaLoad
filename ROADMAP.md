# NovaLoad Roadmap

## v1.0 (Current)
- Multi-connection segmented HTTP/HTTPS engine with Range fallback
- Persistent SQLite queues, categories, scheduler, and SHA-256/512 verification
- Open media stream probe, browser extension bridge, companion CLI
- Optional server-side Gemini AI assistant with preview-and-confirm workflow
- Dark/Light/System themes + English/Persian/Arabic RTL support

## v1.1
- Signed auto-updater feed generation and notarized macOS/Windows CI certificates
- Native Rust `novaload-daemon` IPC parity with Node engine
- Flatpak manifest and Winget / Homebrew packaging formulas

## v1.2
- Sandboxed WebAssembly plugin runtime for third-party file processors
- BitTorrent / Metalink optional provider plugin
